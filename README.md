Networking Labs – HTTP/SMTP, TCP/IP, and Subnetting

Overview

This repository contains a series of hands-on networking labs designed to strengthen understanding of core Internet protocols, network configuration, and IP addressing. Each lab applies real-world tools and analysis techniques to explore how data is transmitted, routed, and segmented across networks.

Labs Included
1. HTTP and SMTP Analysis

Captured and analyzed HTTP and SMTP packets using Wireshark.

Identified transport protocols, ports, message headers, and status codes.

Demonstrated the risks of unencrypted email communication and suggested encryption improvements.

2. TCP/IP Configuration and Diagnostics

Configured network interfaces and explored TCP/IP parameters using ipconfig, netstat, and tracert.

Interpreted routing tables, subnet masks, DNS, and gateways.

Investigated how attackers can use diagnostic tools for network reconnaissance.

3. Subnetting Practice

Calculated subnet masks, prefixes, and available hosts for Class A, B, and C networks.

Defined subnet ranges, host address limits, and broadcast addresses.

Applied subnetting logic to real-world network design scenarios.

Key Skills Demonstrated

Network layer analysis (HTTP, SMTP, TCP/IP)

Subnetting and IP addressing

Routing and gateway configuration

Network troubleshooting and security awareness

Tools & Technologies

Wireshark

Command Line (Windows/Linux/macOS)

TCP/IP Utilities: ipconfig, tracert, netstat, route print
